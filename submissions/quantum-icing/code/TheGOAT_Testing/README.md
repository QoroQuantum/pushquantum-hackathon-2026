# TheGOAT_Testing

Work from one Claude Code session, kept in its own folder so it can be reviewed separately from
the rest of the repo.

| File | What it is |
|---|---|
| `diagnostics.py` | Does a surrogate rank solutions like the referee? Oriented Spearman, ties at the model's optimum, and a verdict: `weak` (rewrite the surrogate), `underdetermined` (add a tie-breaker), `strong` (invest in the sampler). Also `baseline_table` for keeping the classical bar next to every result. |
| `block_fidelity.py` | For a block of r freed arcs of the incumbent (tails kept, heads permuted, so degrees always hold), enumerates every valid rewiring, scores each with the exact LP and measures how well each surrogate ranks them: the existing `network_qlns` sub-QUBO, the LP weak-duality bound, plain hop count, and linear / quadratic models fitted on half the block. Output: `runs/goat/fidelity/`, one JSON per block. |
| `goat_lns.py` | Quantum-proposer LNS. Per step: free r arcs, learn a block QUBO from the cheap exact bound, sample it with Divi (PCE poly encoding; QAOA with W-state + XY; or QAOA warm-started at the incumbent with a 2-exchange mixer that never leaves the permutation space), decode by Hungarian, LP-check the top K. SA on the same QUBO and random rewirings get the same LP budget on the same block. Resumable; banks improvements through the official checker. Output: `runs/goat/lns/<tag>/`. |
| `goat_swaps.py` | Same LNS with swap variables: y_e = 1 if two freed arcs swap heads (a 2-exchange). Any set of disjoint swaps keeps every degree, and the QUBO is the exact second-order expansion of the hop count around the current topology, with a trust region (cost per swap) that keeps the optimum where that expansion holds. PCE poly encoding: r(r-1)/2 swaps on about r qubits. Controls: SA, greedy on single swaps, sampled, random. Output: `runs/goat/swaps/<tag>/`. |
| `optimizer_bench.py` | Same blocks, same learned QUBO, one PCE run per classical optimizer (Monte Carlo, COBYLA, L-BFGS-B, quantum natural gradient, QN-SPSA, QN-SPSA with angles inherited from the previous block): distance to SA's optimum of the QUBO and LP value of the candidates. Output: `runs/goat/optbench/`. |
| `node_insertion.py` | Regrows network(n) from a network(n−1) topology: every degree-preserving insertion of the missing node, scored with the exact LP and the hop count. Output: `runs/goat/insertion/`. |
| `hop_search.py` | Global simulated annealing on the demand-weighted hop count (0.5 ms per evaluation) from random topologies, then the exact LP on the best of the pool: looks for basins far from the hand-in. Output: `runs/goat/hopsearch/`. |
| `load_surrogate.py` | Congestion-aware shortest-path routing: the maximum link load of a feasible routing, an upper bound on the LP where the hop count is a lower one. **Measured and rejected** (REPORT.md §5): 18% above the LP at 68 ms against the exact LP's 60 ms. Kept because the reason it fails — the referee is not expensive at n = 24 — decides where a surrogate is worth having at all. |
| `certify_radius.py` | Proves a solution optimal within Hamming distance r, or finds a better one. Degrees force every radius-k move to be a derangement of the heads of k arcs, so the neighbourhood is finite: 1,128 moves at r = 2, 34,592 at r = 3. Warm dual simplex with `objective_bound` at the incumbent abandons a candidate as soon as it is provably no better (13 ms a move against 60 ms for a cold LP). **network24 is certified at radius 3**: all 35,720 moves refuted in 6 min 21 s (REPORT.md §6). Output: `runs/goat/certify/`. |
| `certify_descent.py` | The radius scan as a search: enumerate every radius-2..r move, take the single best improving one, bank it through the official checker, repeat; stop with a certificate when a pass finds nothing. **Improved `network18` from 473,000 to 472,112 in 247 s**, and a radius-4 pass over 530,145 moves certified that topology at radius 4 — correctly, since the 469,000 later found by `certified_ils.py` is ten arcs away (REPORT.md §7). Output: `runs/goat/descent/`. |
| `bound_prune.py` | Can a cheap valid lower bound replace the LP inside the certificate? LP duality gives one for any nonnegative arc weights, and the incumbent's own duals reproduce its LP to six digits. **Measured and rejected** (REPORT.md §8): every bound is valid, all are 15% too loose, the best prunes 33.5% at 1.5 ms against the 12 ms exact answer — a 1.27x ceiling where radius 5 needs 20x. Output: `runs/goat/boundprune/`. |
| `node_deletion.py` | The reverse of `node_insertion.py`: shrink network(n+1) to network(n) by deleting a node and repairing the four broken degrees, every node and both repairs, each scored with the exact LP. Re-derives the chain from an improved ancestor. **Measured**: the chain's own choice (delete the last node, the only one the nested demand matrices keep aligned) is the best start at every level; and at n = 21, 22, 23 that deletion alone, with no search at that level, already beats QOBLIB's best-known value, so the hours of ILS, PT and QAOA below the top are worth 0.37–2.80%. Output: `runs/goat/deletion/`. |
| `instance_bound.py` | A lower bound on the *instance*: no 2-in/2-out topology can score below it. Demand-weighted hops, the directed Moore bound on how near the graph can be at out-degree 2, and max-load >= average load; plus the 2 arcs out of the busiest node. Microseconds, and it holds on all 20 published instances (asserted in the tests). **Every network hand-in is provably within 28.5-32.3% of optimal**, and against the six proven optima the bound is 1.5-17.9% low, so that is mostly the bound's own slack (REPORT.md §9). Output: `runs/goat/instancebound/`. |
| `certified_ils.py` | Iterated local search whose local search is a proof: kick the incumbent by k arcs (k above the certified radius, distance checked rather than assumed), exhaust radius 2..r, keep the result if it is better. Each stop is a *certified* local optimum, so the by-product is the list of distinct certified optima and their spread — a measurement the team's sampling ILS cannot make. **Took `network18` from 472,112 to 469,000, −0.27% → −0.92% against best known, in five restarts** — a topology ten arcs from the one it left, so outside every certificate here (REPORT.md §10). Validated on network05, where all 61 restarts return to the proven optimum. Output: `runs/goat/ils/`. |
| `build_deck_pdf.py` | Renders the slide deck's own files (index, shared CSS, one `<section>` per slide) to a PDF, one 1920×1080 page per slide, with headless Chrome; speaker notes go to a `.notes.txt` beside it. |
| `summarize.py` | Markdown tables from `runs/goat/`: block fidelity, LNS runs, head-to-head per block. |
| `REPORT.md` | **Start here.** What the measurements say, verdict first. |
| `tests/` | Unit tests on synthetic data. |

## Environment

From the repo root, with Python 3.11 or newer:

```bash
uv venv --python 3.12 venv            # or: python3.12 -m venv venv
uv pip install --python venv/bin/python -r requirements.txt pytest
venv/bin/python -m pytest -p no:cacheprovider TheGOAT_Testing/tests
```
